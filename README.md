# Stock Scout

日本株の銘柄選定と購入予算計算を試すWebアプリ。白基調のLiquid Glass UI。

**公開版は架空240銘柄のデモです。実際の日本株データ・リアルタイム監視・iPhoneプッシュ通知・自動発注は接続していません。**

## 実装機能

- 5日・25日・75日の単純移動平均。設定画面で各期間を変更可能。
- 仮のトレンド条件による候補抽出、短期線の上抜け検出。
- 検索、業種フィルター、並べ替え、保存銘柄、JSON書き出し。
- 1・3・6か月相当のSVGチャート、ポインターと左右キーによる価格確認。
- 予算から購入株数・概算金額・予算残を計算。
- SBI証券トップへのリンク。購入画面への直接遷移・銘柄や株数の入力は未実装。
- モバイルでは銘柄詳細をボトムシートで表示。
- 初回と更新時の全画面スケルトン、アニメーションの軽減設定。

## 技術と選定理由（全体）

| 採用技術 | 使い道と選定理由 |
| --- | --- |
| HTML5 | 意味のある見出し、テーブル、フォームで画面を構成。ブラウザ標準の操作性を利用するため。 |
| CSS Grid / Flexbox / Media Queries | PCの2カラムとスマートフォンの1カラム・ボトムシートを、JavaScriptのレイアウト処理に頼らず実現するため。 |
| CSS backdrop-filter / 多層グラデーション / box-shadow | ガラスのぼかし、透け、縁の反射、白基調の奥行きを表現するため。非対応ブラウザでは白いパネルにフォールバック。 |
| CSS Animations / Transitions | 全画面スケルトンのシマー、パネルの登場、タブ移動、チャート描画、モーダル、背景の緩い動き、波紋を軽量に実装するため。 |
| JavaScript ES Modules | 画面と金融計算を分離し、ライブラリの依存・ビルド工程を増やさずテスト可能にするため。React等は今回の単一画面デモに必要な規模ではないため不採用。 |
| Web Animations API / requestAnimationFrame | 選択時の数値・見出しの変化と集計カウントを、画面の描画タイミングに合わせて動かすため。 |
| prefers-reduced-motion | 端末の視差効果軽減設定を尊重するため。アプリ内にも軽減設定を用意。 |
| インラインSVG | 高解像度のチャートとアイコンを追加ライブラリ・外部画像配信なしで描画し、線のアニメーションやキーボード操作を付けるため。 |
| native dialog / inert / ARIA | モーダルのフォーカス制御・Escapeでの終了・読み込み中の誤操作防止を、ブラウザ標準機能で実装するため。 |
| BigIntの固定小数点計算 | 予算からの株数切り捨てで小数誤差による予算超過を避けるため。価格・予算は小数6桁まで。 |
| localStorage | 保存銘柄、移動平均の期間、予算、軽減設定だけを端末内に保存するため。ログイン不要。サーバーには送信しない。 |
| Web App Manifest / SVG favicon | 対応ブラウザでホーム画面追加時の名称と外観を設定するため。Service Workerは導入せず、オフライン動作・バックグラウンド監視・通知は提供しない。 |
| システムフォント | 日本語の表示を外部フォント通信なしで行い、初回表示を軽くするため。Interをダウンロードする処理はなく、端末にない場合はOSのフォントにフォールバック。 |
| Node.js標準HTTPサーバー | ローカル開発用。追加パッケージなしでES Modulesを正しいMIMEで配信するため。本番ではこのサーバーを使わない。 |
| node:test / node:assert | 移動平均・上抜け・入力検証・予算計算・フィルタリングを依存なしで検証するため。 |
| Git / GitHub | ソースと変更履歴を公開し、ユーザーが継続開発できるようにするため。認証情報・個人の口座データは含めない。 |
| GitHub Pages | 公開用の静的Webアプリを追加サーバー費用なしで配信するため。PC常時起動が不要になる。ただし株価収集や通知のバックエンドは実行できない。 |
| Sites | 同じ静的成果物を本人用の確認環境にも配置するため。GitHub Pagesと同様、現在の公開物に株価監視バックエンドは含まれない。 |

本番ランタイムのnpm依存、外部CDN、外部フォント、解析トラッカーはありません。計算はブラウザ内で完結します。UIの「SBI証券を開く」を操作した場合はSBIサイトへ移動します。

## ローカル実行

Node.js 20以降。

```sh
node scripts/serve.mjs
```

http://127.0.0.1:8766 を開きます。依存パッケージのインストールは不要です。

```sh
node --test tests/engine.test.mjs
node --check dist/app.js
node --check dist/engine.js
```

## 公開と更新

`dist/` が配信成果物です。GitHub Pagesは `gh-pages` ブランチのルートを配信します。

ソースを `main` にコミット・push後、次のコマンドで静的ファイルだけを更新できます。

```sh
git subtree push --prefix dist github gh-pages
```

`github` リモートは本リポジトリを指します。Sites環境は `.openai/hosting.json` のプロジェクトIDとSites公式ワークフローで更新します。Sites用の一時認証情報をコミットしないでください。

## データ・判定の仕様

`dist/engine.js` の `makeDemo()` は固定シードで240個の架空銘柄を生成します。コードはDから始まり、実銘柄の価格として使えません。日付は平日を割り当てただけで、取引所の祝日は反映していません。更新ボタンは同じデモを再読み込みします。基準日は2026年10月30日で固定し、表示更新時刻と区別します。

候補は、短期線 > 中期線 > 長期線、中期線が前日より上向き、終値 > 中期線の3条件すべてに一致する銘柄。上抜けは、前日短期線 <= 前日中期線、当日短期線 > 当日中期線です。利益・勝率は推定していません。出来高やファンダメンタルズの判定は未実装です。

移動平均は長期線の日数+1本以上の正の有限な終値が必要です。グラフの表示期間を変えても、移動平均は全履歴から計算した値を切り出して表示するため、期間変更で値は変わりません。

初回850ms・更新時550msのスケルトン表示時間は、デモUIを確認するための最小表示時間です。通信遅延や実データ取得の演出ではありません。軽減設定では80msに短縮します。実データ接続時はデータ取得状態に連動させる必要があります。

## 未接続・制約

- 実市場全体をカバーする無料データ源は未確定。立花APIの加工制限は解決していません。
- 実際のリアルタイム株価取得、常時監視、通知はありません。
- iPhone Safari実機は未検証。PCブラウザのモバイル幅で動作を確認します。
- ブラウザを閉じると計算処理は停止します。
- 端末間の保存データ同期はありません。共有端末ではブラウザのサイトデータを消すと予算・保存銘柄も消えます。
- 実際の購入はSBI側で本人が行います。注文API・口座認証情報は扱っていません。
